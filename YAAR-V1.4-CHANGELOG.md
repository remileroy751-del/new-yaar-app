# Yaar-App V1.4.0

- Changement du nom de boutique autorisé une fois tous les 30 jours.
- Blocage local + contrôle serveur Supabase avec message indiquant la date disponible.
- Ancienneté de la boutique affichée sur sa vitrine publique à partir de `created_at`.
- À la publication de chaque produit, deux options de discussion repliées par défaut :
  - Discussion interne activée/désactivée
  - Discussion WhatsApp activée/désactivée
- Les boutons de discussion de la fiche produit respectent ces réglages.
- Les produits existants conservent les deux options activées grâce aux valeurs par défaut.
- Version Android : 1.4.0 (versionCode 22).
